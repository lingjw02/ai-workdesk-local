# EMILIA LAB
<!-- impeccable:product-schema 1 -->

## Platform
web

## Product Purpose
A personal Windows AI workbench for delegating goals to Main Brain, persistent project managers, and workers, then reviewing tasks, approvals, and outputs.

## Users
The owner uses this local workspace to coordinate AI work, manage project knowledge, and work with files and personal utilities.

## Capabilities and Constraints
FastAPI serves a vanilla JavaScript/CSS frontend backed by a Python engine and SQLite. Existing task, project, approval, memory, file, media, and settings contracts must remain functional. Some worker capabilities and remote execution remain demonstrations and must not be represented as verified execution. Model configuration is distinct from connectivity.

## Brand Commitments
The user approved retaining EMILIA LAB with subtle character details and a calm personal AI studio direction. Existing snowflake identity and supplied character artwork are retained selectively.

## Approved Workflow
Office/team beside Main Brain / PM conversation; task, approval, output, and project inspection below. Navigation is simplified and all existing tools remain accessible.
