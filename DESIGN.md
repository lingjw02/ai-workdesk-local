# EMILIA LAB design system

## Direction
Personal AI studio, approved 2026-09-15. Operate mode: readable work, visible progress, and restrained character identity.

## Visual system
Graphite canvas, raised charcoal surfaces, pale cool-blue accent, high-contrast off-white text. Character portrait appears in the navigation footer and home welcome area, never behind working text. Sans typography uses locally available Segoe UI for familiar Windows operation; monospace is reserved for code and measurements. Controls use 8px corners; larger panels use 12px. Borders define surfaces; decoration is sparse.

## Layout
Single 224px sidebar, compact global header, scrollable content. Desktop chat uses a resizable office/conversation split with a lower session dock. Mobile uses office/conversation switching and a stacked dock. All tools share headers, form styling, spacing, focus, and disabled states.

## Interaction
Keyboard-operable navigation, command search, visible focus, accurate connection feedback, explicit empty/error states. Reduced-motion preference is honored. Dashboard prioritizes attention items and recent work. No configuration-only online claims.

## Media room

The media page uses a viewing-room layout: one large central preview with playback controls beneath it. File browsing, image/video/audio filters, search, upload, and the expandable queue live exclusively in the right library sidebar. The library collapse preference persists locally; on small screens it opens as an overlay and closes after selection. Filtering updates the collection without replacing the active player. Browser checks cover desktop/mobile layout, preview persistence, search, queue, and audio transport using an in-memory WAV fixture.
